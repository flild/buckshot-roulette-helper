# Contributing to Buckshot Tracker

First off, thank you for considering contributing to Buckshot Tracker! We welcome contributions from everyone.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub using the bug report template. Describe the bug clearly, and include steps to reproduce it if possible.

### Suggesting Enhancements
We welcome feature requests! Please create an issue using the feature request template. Describe the feature and explain how it would improve the project.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes.
4. Make sure your code lints.
5. Issue that pull request!

## Code Style
* Please try to follow the existing coding style in the repository.
* Run `npm run lint` and `npm run typecheck` before pushing your changes to ensure no new errors are introduced.

Thank you!
